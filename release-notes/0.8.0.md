0.8.0 测试版更新

- 新增 远程访问按 LynShen 账号连接：登录后这台电脑出现在同一账号的手机和网页里，其他账号连不上；已配对的设备照常可用
- 新增 `lynshen login --device`：只装 CLI 的电脑也能登录 LynShen 账号（`lynshen logout --device` 退出）
- 新增 排队的消息可以逐条插入、撤回、删除、调整顺序，或中断当前回合后发送；TUI 输入框为空时按 ↑ 取回最后一条
- 新增 桌面端和手机发消息时可以附带任意文件，文件不再写进正文
- 新增 LynShen、Claude Code、Codex 对话都能从任意一轮分叉，原对话不变
- 新增 智能体可以展示交付的文件、图片和视频，提议定时任务，等待另开对话的回复
- 新增 Claude Code、Codex 可以使用自己添加的服务商，只用该服务商的密钥，不计入 LynShen 用量
- 新增 内置 OpenCode、oh-my-pi、Pi 智能体；外部智能体（ACP）支持选模型、设置项、表单和登录
- 新增 对话的 TUI 可以在桌面端其他窗口和手机上查看
- 新增 定时任务保留最近 20 次运行记录，可设单次花费上限、在独立 worktree 中运行；连续失败 3 次自动停用；运行时电脑不会休眠
- 优化 Claude Code：中途发送的消息显示为排队，子智能体和 Workflow 的用量计入本轮，额度提示写明用量和重置时间
- 优化 无人使用 30 分钟的引擎会话自动关闭，再次打开时按原设置继续
- 优化 从 GitHub 安装的技能固定到当前提交，专有许可证的技能只列出不安装
- 修复 Claude Code 设置了 CLAUDE_CONFIG_DIR 时报「Session ID … is already in use」、历史为空
- 修复已知问题
